# CAT CLIMB

A 2D mobile platform game inspired by the Doodle Jump genre.

## Overview

The player controls a cat character and climbs through vertically generated platforms while avoiding hazards and trying to achieve a high score.

The project was developed with Unity and C#.

## Features

* Player Jump
* Player Attack
* Wall Climbing
* Platform Generation
* Platform Destruction
* Object Pooling
* Score System
* Game Over and Restart System

## My Contributions

* Wall climbing system

## Development

The project was developed using Unity and C#.

Object Pooling was used to efficiently manage repeatedly generated gameplay objects such as platforms and obstacles.

I iteratively tested the game and adjusted the systems based on issues found during playtesting.

## AI-Assisted Development

AI tools were used as development assistants during the project.

* ChatGPT and Gemini were used to generate 2D game assets and animation images.
* Antigravity was used to assist with code implementation and debugging.
* Error messages were analyzed with AI to identify possible causes and solutions.
* Gameplay issues discovered during testing were described to AI and investigated iteratively.

The core gameplay ideas and system design were developed by me. AI-generated code and assets were reviewed, modified, tested, and integrated into the project.
